# GitLab-backed marketplace fallback (explicit request only)

Loaded on demand from the Skill Management (`skill-publishing`) skill. Use this path **only**
when the user explicitly wants a GitLab/git marketplace, or the AI Marketplace path is
unavailable and they've chosen GitLab as the alternative. It needs the GitLab MCP server and
GitLab/SSH access, which not everyone at Portico has. Plain installs from a named git catalog are
NOT this path — they use Workflow E in the skill body and need no GitLab access.

- Activate the GitLab MCP server (`server:gitlab-mcp`) for this path; it is not required for the
  default AI Marketplace flow.
- Use `list_marketplaces` / `get_marketplace_skills` / `add_marketplace` / `sync_marketplace` /
  `install_marketplace_skill` / `replace_user_skill_with_marketplace_install` /
  `detach_marketplace_skill_to_user_skill` for the git-backed marketplaces, and the GitLab MCP for
  repo / branch / commit / merge-request actions.
- For `portico-ai-marketplace` (`community/portico-ai-marketplace`), never create a fork as the
  contribution path — fork MRs fail because the CI needs internal variables. Create a branch in the
  target project and open the MR from there.
- If a GitLab branch/commit/MR fails due to missing project permission, GitLab token, or SSH key,
  stop and explain that access/setup must be fixed (request target-project access, configure
  GitLab/SSH, or contact Community / `#help-ai-dev-productivity`). Do not route around it with a fork.
- Merge-request descriptions must be real multiline Markdown (no literal `\n`/`\r\n`) and end with a
  blank line followed by `Generated by Portico`. Send the user a clickable Markdown link to
  every MR as soon as it is opened.
- New marketplace repos use the sparse layout `.atlas-plugin/plugin.json` +
  `skills/<skill_id>/{SKILL.md,references/…,scripts/…}`, with `author.name` = `PORTICO_USER_NAME` and
  `author.email` = `${PORTICO_USER_ID}@example.invalid` (ask if unavailable). After a merge, `sync_marketplace`,
  install the managed copy, and `replace_user_skill_with_marketplace_install` to archive the local copy.
