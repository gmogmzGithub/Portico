### D-01 — Model picker shows available models (Bifrost output)

**Coverage:** Partial — `cargo test --manifest-path src/mcp-orc-rust/Cargo.toml -p health-check`
**Type:** Chat / LLM
**Preconditions:** Bifrost is up; `PORTICO_LLM_API_KEY` available; chat tab focused.

**Steps:**
1. Click the model picker dropdown in the chat header.
2. Compare the listed model IDs against the output of `curl -s http://127.0.0.1:<bifrost-port>/v1/models | jq '.data[].id'`.

**Expected:**
- The OWUI model picker lists the same set of models that Bifrost reports.

**Fail indicators:**
- Picker is empty.
- Picker lists a model that Bifrost doesn't expose.
- Picker missing a model that Bifrost exposes.

### D-02 — Switch models mid-chat preserves conversation history

**Coverage:** Manual
**Type:** Chat
**Preconditions:** A chat with ≥3 message exchanges.

**Steps:**
1. Open the model picker.
2. Choose a different model.
3. Continue the conversation with one more message.

**Expected:**
- All previous messages remain visible after the swap.
- New response is generated by the new model.

**Fail indicators:**
- History blanks out.
- Tab reloads to "New Chat".

### D-03 — Streaming tokens render incrementally; final message persists

**Coverage:** Manual
**Type:** Chat / LLM
**Preconditions:** A model selected.

**Steps:**
1. In a chat, type `Write me a 200-word paragraph.` and send.
2. Observe the response.
3. After completion, scroll up and refresh focus to the chat tab.

**Expected:**
- Tokens stream in (~10–50 per second) — visible character-by-character on screen.
- After completion, the message persists with the same content (no truncation on reload).

**Fail indicators:**
- Whole response appears at once after a long pause.
- Message disappears after completion.

### D-04 — Model access denied (403) shows the temporary CBO-745 message

**Coverage:** Manual (regression #56)
**Type:** Chat / Auth
**Preconditions:**
- A model in the picker that your corporate identity does NOT have access to (e.g. a restricted Bedrock model).

**Steps:**
1. Select the restricted model.
2. Send any message.

**Expected:**
- Inline error message references CBO-745 / model access denial.
- Chat composer remains usable (can switch models and retry).

**Fail indicators:**
- Generic 403 trace.
- Composer locks up.
- No CBO-745 reference.

### D-05 — Conversation list (sidebar) shows all chats; renaming updates the tab title

**Coverage:** Partial — [`tab-hover-title.unit.test.js`](../../../../electron-app/src/services/tab-hover-title.unit.test.js) (regression #63)
**Type:** Chat / Shell
**Preconditions:** ≥2 chats with assistant-generated titles.

**Steps:**
1. Open the OWUI sidebar.
2. Confirm both chats are listed in the conversation list.
3. Right-click a chat → Rename → enter a new title.

**Expected:**
- Sidebar updates the chat title immediately.
- Tab strip's chat tab updates within a second.
- Hover tooltip on the tab shows the new full title.

**Fail indicators:**
- Sidebar updates but tab does not (regression #63).
- Tab updates only after window restart.
