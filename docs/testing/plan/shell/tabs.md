## Scenarios

### B-30 — Open up to 20 chat tabs

**Coverage:** Partial — [`chat-workspaces.test.js`](../../../../electron-app/src/services/chat-workspaces.test.js)
**Type:** Shell
**Preconditions:** Main shell focused; few or no existing chat tabs.

**Steps:**
1. Press `Cmd+T` 20 times.
2. Inspect the tab strip.
3. Press `Cmd+T` once more.

**Expected:**
- 20 chat tabs (plus system tabs) render.
- The strip becomes scrollable.
- The 21st `Cmd+T` either creates a tab and removes the LRU (per [`docs/howto/users/tabs.md`](../../../howto/users/tabs.md)) or is rejected — verify behavior matches the doc.

**Fail indicators:**
- Renderer slows to a crawl past ~10 tabs.
- Tab strip overflows visibly.

### B-31 — LRU suspension >12 tabs

**Coverage:** Manual
**Type:** Shell / Performance
**Preconditions:** 13+ open chat tabs (use B-30 to set up).

**Steps:**
1. Open Activity Monitor → filter for `Portico`.
2. Note current memory of helper processes.
3. Click into the *least recently used* tabs to confirm they reload (lazy resume).

**Expected:**
- Memory does not grow linearly with tab count.
- The LRU tab shows a brief "Loading…" or fast resume rather than instant render.

**Fail indicators:**
- Every tab is fully resident in memory regardless of focus age.

### B-36 — Return detached window with its redock button

**Coverage:** Auto — [`detached-chat-window-policy.test.js`](../../../../electron-app/src/services/detached-chat-window-policy.test.js)
**Type:** Shell
**Preconditions:** A detached chat window (from B-35) and the main shell visible.

**Steps:**
1. Drag the detached chat window's title bar onto the main shell tab strip and release it.
2. Verify it remains detached.
3. Click **Return to Tab** in the detached header.

**Expected:**
- Window movement does not trigger reattachment.
- Window closes.
- The chat reattaches as a tab.
- Session preserved.

**Fail indicators:**
- Releasing the window over the tab strip redocks it.
- Window stays open after clicking **Return to Tab**.
- Tab created without session (cold reload).
